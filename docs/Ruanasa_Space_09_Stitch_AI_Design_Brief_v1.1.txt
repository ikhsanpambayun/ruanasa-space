STITCH AI DESIGN BRIEF

Ruanasa Space — Wellness Event Management Platform

Version: 1.1
Purpose: Input brief untuk Stitch AI agar menghasilkan design system dan UI design yang konsisten dengan product specification Ruanasa Space.


========================================================================
1. PRODUCT OVERVIEW
========================================================================

1.1 Apa itu Ruanasa Space

Ruanasa Space adalah platform berbasis web untuk mengelola aktivitas wellness community secara end-to-end. Pada tahap MVP, fokus pada operasional Yoga Class.

Platform ini menggantikan proses manual (spreadsheet, chat WhatsApp, pencatatan pembayaran terpisah) menjadi satu sistem terintegrasi.

1.2 Target Audience

Participant:
- Member komunitas wellness (yoga, meditation, breathwork)
- Usia 20-45 tahun
- Familiar dengan smartphone dan transaksi digital
- Mengakses via mobile browser (Chrome, Safari)

Admin (Ruanasa Team):
- Pengelola operasional komunitas wellness
- Mengakses via desktop browser
- Mengelola event, peserta, pembayaran, dan analytics

1.3 Brand Positioning

"A digital space to manage wellness experiences, create meaningful moments, and grow a connected community."

1.4 Brand Personality & Tone

- Calm & Welcoming — platform wellness, bukan marketplace agresif
- Clean & Minimal — mengurangi noise, fokus pada konten dan aksi
- Trustworthy — transparan soal harga, status, dan informasi
- Professional yet Warm — serius dalam operasional, hangat dalam komunikasi
- Modern — desain kontemporer, bukan tradisional


========================================================================
2. PLATFORM & DEVICE REQUIREMENTS
========================================================================

2.1 Two Distinct Interfaces

Platform ini memiliki DUA interface berbeda yang harus di-design secara terpisah:

A) Participant Interface (Mobile-First)
   - Primary device: mobile browser (360px - 768px)
   - Secondary: tablet & desktop
   - Navigasi sederhana, linear flow
   - Touch-friendly (minimum tap target: 44x44px)
   - Sticky CTA bar di bottom

B) Admin Dashboard (Desktop-First)
   - Primary device: desktop browser (1280px+)
   - Secondary: tablet (768px - 1279px)
   - Sidebar navigation (collapsible)
   - Data-heavy tables dan forms
   - Hover states, modal dialogs

2.2 Responsive Breakpoints

- Mobile: < 768px (single column, hamburger menu jika admin)
- Tablet: 768px - 1279px (collapsed sidebar admin, 2-column layout)
- Desktop: ≥ 1280px (full sidebar admin, multi-column layout)

2.3 Browser Support

Chrome, Safari, Firefox, Edge (2 versi terakhir masing-masing).


========================================================================
3. DESIGN PRINCIPLES
========================================================================

Lima prinsip design yang HARUS tercermin di setiap halaman:

3.1 Simple
Mengurangi kompleksitas proses registrasi. Participant dapat mendaftar event dalam hitungan menit dengan minimal input. Tidak ada UI yang membingungkan.

3.2 Trustworthy
Memberikan informasi jelas terkait event, harga, discount breakdown, pembayaran, dan status registrasi. Tidak ada biaya tersembunyi. Setiap angka transparan.

3.3 Operational Efficiency
Mempermudah admin mengelola event, peserta, pembayaran, dan feedback dalam satu dashboard tanpa berpindah platform. Dense but readable data display.

3.4 Consistent
Menggunakan design tokens (warna, typography, spacing) yang konsisten di seluruh halaman untuk membangun familiarity. Satu component = satu behavior di mana pun.

3.5 Accessible
Touch-friendly untuk mobile, keyboard-navigable untuk desktop, readable font size (minimum 14px body, 12px caption), dan kontras warna yang memadai (WCAG AA minimum).


========================================================================
4. DESIGN TOKEN REQUIREMENTS
========================================================================

Stitch AI harus menghasilkan design tokens lengkap untuk kategori berikut:

4.1 Color System

WAJIB memiliki:

Primary Color:
- Harus mencerminkan wellness, calm, nature
- Digunakan pada: CTA buttons, active states, links, primary actions
- Minimal 5 shade (50, 100, 300, 500, 700, 900)

Secondary Color:
- Warna pendukung/aksen
- Digunakan pada: secondary buttons, accent elements, highlights
- Minimal 5 shade

Neutral/Gray Scale:
- Skala abu-abu lengkap untuk text, border, background, divider
- Minimal 10 shade (50, 100, 200, 300, 400, 500, 600, 700, 800, 900)
- Gray-50/100 untuk backgrounds
- Gray-200/300 untuk borders dan dividers
- Gray-500/600 untuk secondary text
- Gray-800/900 untuk primary text

Semantic Colors (masing-masing minimal 3 shade: light, base, dark):
- Success (hijau): pembayaran berhasil, registrasi confirmed, hadir, aktif
- Warning (kuning/amber): pending payment, pending registration, event hampir penuh
- Danger (merah): expired, failed, error states, delete action, full
- Info (biru): informational badges, early bird, bundle discount, tips

Background Colors:
- Page background (sangat terang/putih)
- Card background (putih atau sedikit lebih terang dari page)
- Sidebar background (admin — bisa gelap atau terang)
- Overlay/modal backdrop

4.2 Typography

Font Family:
- Sans-serif modern yang mendukung Bahasa Indonesia (karakter Latin)
- Rekomendasi: Inter, Plus Jakarta Sans, atau font wellness-appropriate
- Pastikan tersedia di Google Fonts (gratis)

Type Scale (harus didefinisikan dengan px size, line-height, dan font-weight):
- Display: untuk hero/landing jika diperlukan
- Heading 1: 24-32px / bold — judul halaman
- Heading 2: 20px / semibold — section title
- Heading 3: 16px / semibold — sub-section, card title
- Body Large: 16px / regular — prominent body text
- Body: 14px / regular — paragraph text, form labels
- Body Small: 13px / regular — secondary information
- Caption: 12px / regular — helper text, timestamps, secondary info
- Overline: 11px / medium uppercase — badge text, status label

4.3 Spacing System

Menggunakan 4px base grid:
- 4px (xs) — micro spacing
- 8px (sm) — tight spacing between related elements
- 12px (md) — default internal padding small elements
- 16px (lg) — card padding mobile, gap between elements
- 24px (xl) — card padding desktop, section spacing
- 32px (2xl) — between major sections
- 48px (3xl) — page-level spacing

Specific patterns:
- Card internal padding: 16px (mobile), 24px (desktop)
- Gap between cards/sections: 16px (mobile), 24px (desktop)
- Page side padding: 16px (mobile), 24-32px (tablet), 0 (desktop with max-width container)

4.4 Border Radius

- Small: 4px — input fields, badges, small tags
- Medium: 8px — cards, buttons, containers
- Large: 12px — modals, bottom sheets, large panels
- Full: 999px — avatars, circular badges, pills

4.5 Shadows & Elevation

Definisikan minimal 3 level shadow:
- Shadow-sm: subtle shadow untuk cards
- Shadow-md: dropdown, floating elements
- Shadow-lg: modal, overlay panels

4.6 Animation & Transition

- Default transition: 150-200ms ease
- Page transitions: 200-300ms
- Toast auto-dismiss: 4000ms
- Skeleton shimmer animation
- Button hover/press transitions

5. COMPONENT LIBRARY
========================================================================

Stitch AI harus men-design component berikut beserta SEMUA variants dan states:

5.1 Buttons

Variants:
- Primary: brand color, untuk CTA utama (Daftar, Bayar, Publish, Simpan)

States per variant: Default, Hover, Active/Pressed, Focus, Disabled, Loading (spinner)

Sizes: Small (32px height), Medium (40px height), Large (48px height)

Types yang dibutuhkan:

8. UI PATTERNS & INTERACTIONS
========================================================================

8.1 Price Display Pattern

Tiga skenario yang harus di-design:

A) Normal Price Only:
   "Rp 150.000"

B) Early Bird Active:
   "Rp 150.000" (dicoret, smaller)
   "Rp 120.000" (prominent)
   Badge: "Early Bird" (info color)

C) With Bundle Teaser:
   Price + teks kecil: "Daftar 2 orang diskon 10%"

8.2 Slot/Capacity Indicator Pattern

Tiga state:
- Normal: "X slot tersisa" (neutral text)
- Almost Full (sisa ≤ 10%): "Sisa X slot!" (warning color) + badge "Hampir Penuh"
- Full: "Event Penuh" (danger color, card slightly dimmed)

8.3 Registration Stepper Pattern

5 steps, linear progression:
- Completed steps: checkmark + muted color
- Current step: highlighted/active
- Upcoming steps: numbered + muted

8.4 Payment Countdown Pattern

- Timer format: MM:SS
- Normal: neutral display
- < 10 minutes: warning color
- Expired: danger color + "Waktu pembayaran habis" message

8.5 Loading Patterns

- Full page: centered spinner + "Memuat..." text
- Skeleton: gray placeholder shapes (cards, table rows, text)
- Inline: spinner inside button during processing ("Memproses...")
- Lazy: poster images load saat masuk viewport

8.6 Empty State Pattern

Setiap konteks memiliki empty state berbeda:
- Event Listing: "Belum ada event tersedia saat ini."
- Participant List: "Belum ada peserta terdaftar untuk event ini."
- Payment List: "Belum ada transaksi pembayaran untuk event ini."
- Attendance: "Belum ada peserta yang dikonfirmasi untuk event ini."
- Feedback: "Belum ada feedback untuk event ini."
- Event History: "Anda belum mengikuti event apapun."
- Notification: "Tidak ada notifikasi baru."
- Template List: "Belum ada template. Buat template pertama Anda."
- Promo Code List: "Belum ada promo code."

8.7 Toast/Notification Pattern

- Success: "Event berhasil dipublikasikan", "Data tersimpan", "Pembayaran berhasil"
- Error: "Terjadi kesalahan, silakan coba lagi", "Gagal menyimpan"
- Warning: "Koneksi internet terputus"
- Position: bottom-center (mobile), top-right (desktop)
- Auto-dismiss: 4 detik

8.8 Confirmation Modal Pattern

Untuk destructive/important actions:
- Publish Event: "Publish event ini? Event akan terlihat oleh publik."
- Complete Event: "Tandai event selesai? Status tidak dapat diubah kembali."
- Delete Event: "Hapus event ini? Data yang terhapus tidak dapat dikembalikan."
- Delete Instructor: disabled jika terhubung event Published, tooltip jelaskan
- Layout: title + description + Cancel button (secondary) + Confirm button (primary/danger)

12. MOOD & VISUAL DIRECTION
========================================================================

12.1 Mood Keywords

- Calm, Serene, Balanced
- Clean, Minimal, Spacious
- Natural, Organic, Earthy
- Modern, Contemporary, Fresh
- Warm, Welcoming, Approachable

12.2 Color Direction

- Lean towards earthy/nature tones (sage green, warm neutral, soft earth)
- Avoid aggressive/loud colors (neon, bright red as primary)
- White/light background dominant
- Subtle color accents, not overwhelming
- Semantic colors standard (green=success, red=danger, yellow=warning, blue=info)

12.3 Typography Direction

- Clean sans-serif (Inter, Plus Jakarta Sans, atau rekomendasi Stitch AI)
- Good readability di mobile
- Clear hierarchy antara headings dan body text
- Support Indonesian characters

12.4 Visual Style

- Generous whitespace
- Soft shadows (not harsh drop shadows)
- Rounded corners (medium — 8px default)
- Subtle dividers (thin lines atau spacing, bukan thick borders)
- Photography: poster images full-color, tidak di-filter
- Icons: outline style (Lucide), consistent stroke width

12.5 What to AVOID

- Dark/heavy UI themes (optional for dark mode, tapi primary experience harus light)
- Overly decorative elements (patterns, textures, gradients as decoration)
- Cramped layouts (always prioritize breathing room)
- Inconsistent icon styles (mixing filled and outline)
- Small touch targets on mobile (minimum 44x44px)
- Low contrast text on colored backgrounds
